# WebUI 美术风格约束

本文只用于约束 coding agent 生成或修改 WebUI 代码。页面行为与 URL 状态见 [frontend.md](frontend.md)。

## 必须遵守

- 保持浅色、冷灰背景、白色内容面、蓝色主色的克制风格，不主动重新设计现有页面。
- 优先使用 Naive UI 组件和 `GlobalThemeOverrides`，图标统一使用 `@lucide/vue`。
- 复用现有视觉值：
  - 主色 `#2563eb`，hover `#1d4ed8`，pressed `#1e40af`。
  - 页面背景 `#f4f6fb`，主要文字 `#111827` / `#101828`，辅助文字 `#667085`。
  - 普通控件圆角 6px，卡片圆角 8px。
  - 间距优先使用 8、12、14、16px。
- 内容最大宽度保持 1440px；沿用 900px 应用壳切换点和 720px 内容单列切换点。
- 同一区域只保留一个主操作。危险操作使用 error 语义，并明确说明影响范围。
- 状态不能只靠颜色表达；使用文字、图标、Tag 或结构差异补充。
- 图标按钮必须有可见文字、tooltip 或 `aria-label`。
- 长标题、路径、标签和筛选摘要必须换行或省略，不能撑破容器。
- 覆盖加载、空结果、错误、禁用和成功状态；保留清晰的 hover、focus、按下和选中反馈。
- 触摸设备不能依赖 hover 才能访问关键操作。

## 禁止事项

- 不引入新的基础组件库、图标体系或 Emoji 功能图标。
- 不随意增加品牌色、字号、圆角、间距体系或局部暗色主题。
- 不滥用阴影、悬浮卡片、胶囊圆角、高饱和渐变、玻璃拟态和装饰动画。
- 不重复实现 Naive UI 已提供的 Button、Input、Select、Modal、Alert、Tag 等组件。
- 不用绝对定位修正常规布局，不使用无依据的高 `z-index`。
- 不移除键盘焦点样式，除非提供等效且清晰的替代。

视觉值的代码来源是 `webui/src/App.vue` 中的 `GlobalThemeOverrides` 和 `webui/src/style.css`；两者与本文不一致时，agent 应先核对现有页面，再统一修改规范与实现。
