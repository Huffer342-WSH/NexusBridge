# 媒体库与字幕能力开发任务

本文记录媒体库、目录监控和 MKV 字幕能力的后续开发任务。稳定行为完成后再分别归入架构、API、存储和播放文档。

## 目标模型

- 媒体库是目录、计划任务和功能设置的作用单元。
- 普通媒体库像目录一样形成不限层级的父子树；子节点默认继承父节点设置，本地显式值覆盖继承值。
- `collection` 表示可继续包含下级的普通媒体库；`series` 表示叶子剧集，点击后直接进入旧剧集选集与播放页。
- 集合可以在后续扫描中识别候选子目录，并按策略创建剧集型子媒体库。
- 站点、数据库种子和 qB 关联都是可选信息；本机实际文件及其所属媒体库才是目录功能的基础。

## 阶段一：媒体库雏形

- [x] 统一媒体库节点类型、父子关系和可继承设置模型。
- [x] 保留 `/api/series` 和剧集播放 URL，现有剧集自动视为 `series` 节点。
- [x] 提供媒体库 CRUD、树形管理页、统一内容页和所有节点的手动重扫。
- [x] 普通媒体库能作为父节点，剧集不能拥有下级；子媒体库目录必须位于父媒体库目录内，并拒绝父子循环。
- [x] 普通媒体库内容页混合展示直接子媒体库与扫描媒体，以图标区分；父节点扫描排除子媒体库负责的目录。
- [x] 有子节点的媒体库不能直接删除；所有删除只影响配置和缓存。
- [ ] 根据实际使用反馈确定集合是否允许多个目录，以及是否放宽全局名称唯一约束。

## 阶段二：目录监控与文件索引

- [ ] 为媒体库目录建立启动扫描和后台增量扫描；手动扫描已完成。
- [x] 当前使用低频完整扫描发现目录变化；首次启动和人工重扫检查全部 MKV，周期扫描只预热新增、大小变化或修改时间变化的 MKV。
- [x] 记录规范路径、相对路径、大小、修改时间和可用状态；字幕产物使用独立内容指纹。
- [ ] qB 文件以单文件完成进度判断稳定；非 qB 文件使用大小和修改时间稳定窗口。
- [x] 媒体库扫描排除已有直接子媒体库负责的目录，避免重复展示和批处理。
- [ ] 为媒体库设置可继承的监控、自动发现剧集和任务策略。
- [ ] 自动发现只生成候选项或按明确策略创建子剧集，避免目录名误判造成不可控增殖。

## 阶段三：字幕持久化

- [x] 使用源文件路径、大小、修改时间和轨道 ID 生成字幕产物指纹。
- [x] 媒体库启动扫描、周期扫描、人工重扫和播放请求共用字幕产物服务及规范路径防重队列。
- [x] 缓存缺失时继续使用进程内 `mkvgo` 快速提取；成功响应同时原子持久化。
- [x] 后台任务与播放请求按产物键防重；播放请求可以等待正在执行的同一任务。
- [x] SRT/WebVTT 持久化标准 VTT；ASS/SSA 同时保存保留样式的 ASS 和 VTT 降级产物。
- [ ] 提取 MKV 中被字幕引用的字体附件，并限制单文件、总量、数量和允许类型。
- [x] 绕开当前 `mkvgo ExtractASS` 固定三秒结束时间，优先使用 BlockDuration、下一条时间和末条兜底。
- [x] 持久化写入失败时仍允许临时结果完成本次字幕加载。
- [x] 源文件变化后使用新指纹；只有成功扫描确认视频消失且文件不存在时清理其旧产物。

## 阶段四：浏览器富字幕

- [x] 接入 `artplayer-plugin-jassub`，ASS/SSA 默认使用 libass WASM/WebGL 渲染。
- [x] JASSUB 不可用、初始化失败或资源不足时自动降级到同轨 WebVTT。
- [ ] 验证无字幕、单字幕、多字幕、字体附件、时间偏移和字幕关闭行为。
- [ ] 真实浏览器验证普通全屏、网页全屏、画中画和移动端；覆盖层字幕不预设可随原生画中画或 AirPlay 输出。
- [x] PGS/VobSub 等图片字幕明确不开发，不执行 OCR、烧录或图片覆盖层转换。

## 安全与副作用边界

- 不转码音视频，不调整 qB 文件优先级，不修改或删除媒体源文件。
- 目录扫描、自动建剧集和字幕任务必须有并发、内存、产物大小和路径边界。
- fake/offline 检查不能表述为真实 qB、真实媒体或真实浏览器播放证明。
- 新增或改写测试前，先说明目标、fake/真实方式、环境和副作用并等待批准。
