# 视频浏览与 qB 管理开发规划

更新时间：2026-11-14。

本文是本轮开发的统一规划与进度入口。目标是让用户通过视频画面浏览、播放已有下载，并直接管理所属 qBittorrent 任务，不必根据不规范的文件名重新寻找任务。

## 已确认的方向

- 自动下载由 qB 负责，NexusBridge 本轮重点是浏览和管理；现有站点抓取和订阅能力保留，不扩展。
- 支持从本机目录及 qB 下载内容浏览视频，展示预览图。
- 支持在线播放，并计划接入 PotPlayer 等外部播放器。
- 从视频直接查看关联任务，删除任务及文件、移动任务保存位置或修改分类。
- 继续开发 NexusBridge，不迁移到其他项目。

预览图优先复用视频截图能力，不以文件名能否匹配影视海报作为浏览前提。视频文件与任务不一定一一对应：合集包含多个视频，同一文件也可能被多个任务共享。

## 实施约束

- 删除和移动按任务处理；单个视频条目不能让用户误以为操作仅影响该文件。
- 多任务关联必须明确列出，不自动选取第一个任务，不隐式批量删除。
- 分类由 qB 管理；修改分类不必然移动文件，取决于自动管理状态和相关设置。
- 浏览器播放继续沿用现有源文件播放方案，本轮不预设增加转码。
- 外部播放器接入方式待部署信息确认，不把服务器本地路径当作客户端可访问路径。
- 不提交真实凭据、真实 HTML 响应或带凭据的命令。

| 检查 | 结果 |

| `git diff --check` | 首批代码改动检查通过 |
| 新增或改写测试 | 已获批准；`go test ./tests -run ^TestFileQBExactAssociation$ -count=1` 通过，覆盖单文件、合集、多任务、无关文件和清单失败 |
